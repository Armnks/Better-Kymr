# KymrStudio — A Living Digital World

A scroll-driven cinematic organism. Not a website with animations — a single evolving visual composition of 11 morphing states, built as the creative work itself.

## Experience
- 01 ORIGIN — ember dot ignition → hairline → aperture → wordmark (cursor-repelled letters)
- 02 EXPANSION — KYMRSTUDIO scales beyond the viewport; the O counter becomes a circular window
- 03 SIGNAL — WE MAKE THINGS PEOPLE WATCH. collides, slices, reforms
- 04 PROTOCOL — 48H / 3S / 100% / 10+ morphing installation
- 05 FORCES — STRATEGY → CREATIVE → PRODUCTION → EDITING → PERFORMANCE as colliding forces
- 06 SILENCE → 07 INVERSION — the void ring consumes the screen and flips the world
- 08 ARCHIVE — THE ARCHIVE IS JUST BEGINNING. (no fake portfolio, ever)
- 09 TRANSIT — vertical scroll becomes horizontal travel
- 10 KYMRSTUDIO — letters converge from the corners and lock
- 11 CONTACT — the final frame: media@kymrstudio.com

## Systems
- Loading ritual with returning-visitor ember blink (localStorage)
- Synthesized ambient room tone (Web Audio, off by default, gesture-gated)
- Seeded daily variation, velocity-reactive atmosphere, morphing nav, contextual cursor
- Reduced-motion fallbacks for every state

## Stack
React 19 · GSAP ScrollTrigger · Lenis · Tailwind · FastAPI · MongoDB (legacy enquiry vault at /admin)

## Run
- Frontend: `cd frontend && yarn && yarn start`
- Backend: `cd backend && pip install -r requirements.txt && uvicorn server:app --port 8001`
- Env via `backend/.env` (MONGO_URL, DB_NAME, ADMIN_KEY) and `frontend/.env` (REACT_APP_BACKEND_URL) — never committed
